# 标书中心 V1 内容分类

- 日期：2026-09-04
- 状态：第 0 步候选分类，等待历史样本验证

## 1. 分类原则

每项内容先判断“归属哪个包”，再判断“是模板结构、可复用组件、项目数据还是附件”。同一份正文不得在多个模板中形成无法同步的复制品。

内容归属：

- `technical`：工程设计、设备、制造、检验和技术承诺。
- `commercial`：价格、付款、交货、合同和法律商务承诺。
- `common`：公司身份、资质、业绩、品牌和通用说明。

内容形态：

- `template_section`：决定包的章节结构和默认顺序。
- `clause`：可被多个章节或模板引用的受控条款。
- `content_block`：可复用正文、表格、图片或资料说明。
- `variable`：从 CRM、报价或项目手工输入的结构化值。
- `asset`：证书、图纸、图片或其他受控附件。

## 5. 容易混淆的边界

| 内容 | 技术包 | 商务包 | 冻结规则 |
|---|---|---|---|
| 技术质保 | 性能、材料、设备能力保证 | 质保期限、费用和责任限制 | 两边分别表达，并引用一致变量 |
| 交货期 | 技术文件、制造和现场计划 | 合同交货周期和迟延责任 | 商务值为正式承诺，技术计划不得冲突 |
| 供货范围 | 工程范围和接口 | 报价包含项和价格范围 | 使用统一范围代码并做一致性检查 |
| 除外项 | 技术不供内容 | 商务不含价格或责任 | 两包分别列出，完整标书生成时对照检查 |
| 验收 | 技术指标和测试方法 | 验收付款、责任和时限 | 技术指标由技术审批，商务结果由商务审批 |
| 备件 | 技术规格和建议数量 | 价格、付款和供应期 | 共享备件行身份，字段分包管理 |
| 法规标准 | 设计和制造标准 | 合规声明及合同责任 | 标准编号共享，承诺正文分包审批 |

## 6. 内容组件必填元数据

每个条款、正文块或资产必须包含：

- 稳定代码和修订号。
- 中文、英文或双语标记。
- 技术、商务或通用归属。
- 标题、内容类型和适用章节。
- 适用产品族、型号、行业、国家和客户类型。
- 生效、失效、启用和修订状态。
- 内容责任角色、审批人和变更摘要。
- 条件规则和允许引用的变量。
- 如有文件：原文件名、MIME、大小和 SHA-256。

## 7. 模板与内容组件关系

- 模板决定标准章节、顺序、默认组件和变量要求。
- 内容组件独立修订；模板发布时冻结被引用组件的准确修订。
- 项目创建时再次冻结模板和全部组件快照。
- 项目增加或移除组件属于项目修改，不改变模板。
- 项目修改建议回库时创建组件或模板的新草稿，不更新历史修订。

## 8. 样本验证任务

收到历史标书后，对每个章节执行：

1. 分配 TECH、COMM 或 COMMON 代码。
2. 判断模板、条款、内容块、变量或资产形态。
3. 标记在多少份标书中重复出现。
4. 标记是否完全一致、轻微变化或项目专用。
5. 标记内容责任人和审批角色。
6. 标记是否包含价格、客户、工程或法律敏感信息。
7. 记录无法归类或冻结规则冲突，提交业务确认。
