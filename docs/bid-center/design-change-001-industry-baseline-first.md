# 设计变更记录 DC-001：行业基线优先

- 日期：2026-09-04
- 状态：Approved for Step 0 planning
- 用户指令：`你按照行业标准做法涉及规划`
- 关联冻结规范：`../superpowers/specs/2026-09-04-bestcrm-bid-center-v1-design.md`

## 变更原因

BESTCRM 仓库当前没有可授权复用的历史客户标书。用户明确要求由实施方按照行业标准做法完成设计规划，因此第 0 步改用正式行业来源、合成夹具和安全默认规则建立基线，企业历史样本降为后续校准材料。

## 影响

| 范围 | 影响结论 |
|---|---|
| 业务范围 | 不变；仍为技术包、商务包、完整标书、受控组件、审批和输出记录 |
| 数据模型 | 不增加 V1 对象；要求项、来源、修订、责任人、评审和审批元数据按既有规划实现 |
| 权限 | 不变；继续执行服务器端 RBAC、商机可见性、章节分派和职责分离 |
| 输出 | `output-style-v1.md` 由候选样式转为行业基线 R1；企业品牌可通过后续样式修订校准 |
| 验收 | 第 0 步使用行业来源、合成数据和明确默认规则；不再要求历史客户文件作为第 1 步启动条件 |
| 迁移 | 无；本变更只影响实施基线，不新增数据库迁移 |
| 部署 | 无；不修改服务器，不启用功能开关 |

## 不变的安全边界

- 不编造或默认批准工程参数、价格、业绩、证书和合同承诺。
- 客户招标文件、法律法规、强制标准和公司批准政策高于行业默认值。
- 真实历史标书如后续提供，先登记、脱敏和授权，再用于校准或测试。
- 在用户确认第 0 步前，不编写迁移或产品代码。
