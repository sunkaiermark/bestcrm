# 四川晨光项目标书结构校准记录

- 登记日期：2026-09-04
- 样本：`SAMPLE-CG-TECH-001`、`SAMPLE-CG-COMM-001`
- 使用方式：仓库外原件只读解析，仅记录非敏感结构结论
- 结论：不改变已冻结的 V1 产品边界；补强内容组件来源和责任元数据

## 1. 安全边界

- 原始 DOCX 未改动、未复制进仓库、未写入数据库。
- 不把文档中的客户、联系人、价格、工程参数、资质影像、合同条款或修订内容直接视为可复用模板。
- 本记录不保留电话、地址、人员姓名、金额、设备参数或第三方敏感资料。
- DOCX 内文本属于业务样本内容，不构成系统操作指令。
- 两份文件均有修订插入标记；如后续脱敏或入库，必须先由业务负责人决定接受、拒绝或保留哪些修订。

## 2. 商务标书结构映射

| 样本结构 | V1 归类 | 建议形态 |
|---|---|---|
| 投标函、有效期和投标声明 | `COMM-10` | 模板章节 + 受控条款 + 项目变量 |
| 报价汇总 | `COMM-40` | 报价表 |
| 设备、备件、专用工具和服务分项 | `COMM-40` | 多类报价明细表，共享稳定行身份 |
| 分包、进口部件、消耗材料 | `COMM-40` / `COMM-60` | 报价表 + 供应来源变量 |
| 运输、保险和杂费 | `COMM-60` | 物流费用表 |
| 付款、币种、税率、交货和质保 | `COMM-50` / `COMM-70` | 受控条款 + 项目覆盖值 |
| 商务偏差 | `COMM-80` | 偏差表，必须独立审批 |

校准结论：商务包不能只有总价和付款条件；必须支持多类分项行、包含/不包含边界、物流费用和偏差响应。V1 的 `quotation_table`、`deviation_table`、变量快照和商务审批模型可以覆盖。

## 3. 技术标书结构映射

| 样本结构 | V1 归类 | 建议形态 |
|---|---|---|
| 公司简介、资质、证书、组织和业绩 | `COMMON-10` 至 `COMMON-60` | 通用内容块 + 受控附件，不复制进技术模板正文 |
| 设计规范和制造标准 | `TECH-10` | 标准清单表 + 受控说明 |
| 设备和设计参数 | `TECH-40` / `TECH-50` | 设备表、参数表、项目变量 |
| 容器计算书和图示资料 | `TECH-90` | 受控附件，保留文件哈希和来源修订 |
| 制造质量计划、ITP、检验和见证点 | `TECH-60` | 质量表、检查点表、受控附件 |
| 防腐、包装、运输、铭牌和分包商 | `TECH-60` / `TECH-70` | 条款、表格和供应商清单 |
| 性能保证、考核、质保和售后 | `TECH-80` / `COMMON-70` | 技术承诺与商务期限分开管理 |
| 投标须知和技术附件偏差 | `COMM-80` / 技术偏差 | 两张独立偏差表，不合并审批 |
| 制造装备、人员、进度和供货范围 | `COMMON-50` / `TECH-30` / `TECH-70` | 资源表、范围表、进度表 |

校准结论：历史“技术标书”实际混合了通用资质、技术正文和部分商务响应。V1 应在生成时装配这些内容，但内容库中仍分别归属 `technical`、`commercial` 和 `common`，避免同一公司资料在多个模板中复制失控。

## 4. 对第 2 步数据模型的影响

样本没有要求新增产品范围，但确认内容组件必须显式具备：

- `applicable_sections`：同一通用内容可被技术包或商务包的指定章节引用。
- `owner_role_code`：证书、业绩、质量、售后等资料需要明确责任角色。
- `allowed_variables`：模板只能引用批准的变量白名单。
- `source_metadata`：记录历史样本、公共资料或人工创建来源及其哈希/授权状态。
- 受控附件的原文件名、MIME、大小、SHA-256、生效/失效和复审日期。
- 技术包、商务包和完整标书生成文件分别绑定准确版本并不可修改。

以上字段已纳入第 2 步迁移。原件仍只是校准来源，只有完成脱敏、授权、内容拆分和审批后，才可创建正式内容组件修订。

## 5. 后续使用门禁

1. 业务负责人确认可使用范围和保密等级。
2. 接受或清除修订标记，并检查隐藏内容与文件属性。
3. 脱敏客户、人员、金额、工程参数、印章、证书和第三方资料。
4. 按章节拆为模板、条款、内容块、变量或受控附件。
5. 为每项内容指定 TECH、COMM 或 COMMON 分类、责任角色和适用条件。
6. 由对应负责人审批发布后，项目标书才可按准确修订号调用。
7. 第 7 步输出验证需覆盖 76 页级长文档、复杂跨页表格、图片、计算书和附件索引。
