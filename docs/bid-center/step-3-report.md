# BESTCRM 标书中心 V1 第 3 步实施报告

- 日期：2026-09-04

- 分支：`codex/bid-center-v1`
- 生产影响：无

## 完成范围

- 新增商务包模板库，覆盖创建、元数据维护、修订、20 节结构化编辑、提交、发布和退役。
- 商务包模板修订号使用冻结规则 `CTPL-Rn`；发布版本保持不可变，新修订从现有版本受控复制。
- 新增标准条款库和公共资料库，支持技术、商务、通用三类内容及 narrative、表格、图片、受控附件等组件类型。
- 标准条款和公共资料分别建路由和筛选入口，未混用“条款”和“资料”语义。
- 内容组件支持适用国家、行业、产品族、客户类型、章节、允许变量、来源、敏感级别、生效日、到期日和复审日。
- 公共资料附件保存原始文件名、类型、大小、存储路径和 SHA-256；下载只通过受权路由，不暴露静态目录。
- 启用功能开关后，左侧导航按冻结结构显示“标书中心 / 项目标书 / 技术包 / 商务包 / 标准条款 / 公共资料库 / 输出记录”。第 4 步及以后入口保持禁用提示。
- 现有 `/technical-templates` 保持技术包兼容入口，`/technical-clauses` 继续承载原技术条款，不在本步改写其业务语义。

## 权限和安全

- 商务经理负责商务包模板及其拥有的商务/通用内容发布；技术经理负责技术及其拥有的通用内容发布。
- 管理员可检查记录，但不能替代技术经理或商务经理完成业务发布。
- 纯技术角色不能通过菜单或直接 URL 查看商务模板和敏感商务内容；商业侧角色不能发布技术经理拥有的内容。
- 列表、详情、创建、编辑、生命周期动作和附件下载均经业务服务层复核权限；不能依赖菜单隐藏作为安全边界。
- 非拥有者只读取当前已发布修订，最新草稿的标题、敏感级别、附件和状态不会泄露到发布列表。
- 表单输入限制模板/脚本语法、枚举、长度、日期顺序、变量名和引用 ID；multipart 上传完成解析后仍校验 CSRF。
- `BID_CENTER_ENABLED` 默认保持 `false`；关闭时路由在仓储访问前返回 404，页面和导航均不可见。
