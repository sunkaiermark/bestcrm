## 第 8 步发现并修复

1. 客户修订稿原先无法在商务包未冻结交货期时修改交货期。现在允许继承后修改；如已批准商务包明确冻结交货期，则不一致输入以 409 拒绝。
2. 正式标书邮件原先仍走旧附件快照。现在优先使用受控 `complete_pdf`、`attachments_zip` 和 `manifest_json`，尚未生成新输出时才回退到旧快照。
3. 移动页面的输出记录宽表会撑大整个文档。现在只让输出表容器横向滚动。
4. 完整标书的商务审批记录原先回退显示用户数字 ID。商务稿查询现在带出提交人和审批人显示名称，Word/PDF 均已复验。
5. 原封面资产为深色背景白色字标，在白底 Word 页面上只有橙色字母可见。白底文档改用深蓝/橙色资产，并把生成器版本提升到 `v1.0.1`，避免旧输出与新输出混用。

## 回退方案

- 暗部署期间功能关闭；如代码或健康检查异常，先使用 `rollback-production.sh code <previous-version>` 把 `/opt/bestcrm/app` 原子切回上一不可变版本。
- 六个迁移为增量建表/约束，功能关闭时不改变既有业务入口。不得手工删表或逆向改数据。
- 如必须连数据回退，使用部署前由 `backup-production.sh` 生成并校验 SHA-256 的 `database.sql`、`uploads.tar.gz` 和 `manifest.txt`，再执行显式确认的 full rollback。
- 回退后重新检查服务、健康接口、登录、商机页、文件目录权限和标书中心 404 状态。
