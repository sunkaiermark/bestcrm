# 二维 CAD 只读预览

第一版处理已解密后上传的 DWG、ASCII DXF。没有绿盾解密功能，没有三维编辑，不生成 PDF，也不改变附件原文件、提交状态和审批状态。

## 查看

在商机附件处点击“预览”。支持模型空间缩放、平移、全图、图层开关、全屏，以及布局内实体切换。沿用商机访问权限，每次读取图纸数据重新检查权限、附件所属商机和移除状态。图纸数据使用 private/no-store，不生成公开链接，不请求第三方预览网站或 CDN。中文字体随系统自托管。

预览是辅助查看，不等同于原生 CAD。纸空间视口的模型投影、外部参照、图片、代理对象、特殊字体可能不完整；页面会提示相关已检测到的情况。SHX 原字形不保证一致，中文使用 Noto Sans SC。需要核对尺寸、字体、图框和具体 DWG 版本后才能验收。不能承诺任意复杂图纸完全还原。

## 尺寸测量

模型空间可点选两点，显示两点距离、水平距离、垂直距离。坐标来自图纸，不按屏幕像素计量。识别 HEADER 中的 $INSUNITS，支持已知单位换算；单位未定义时标注图纸单位，也可手动指定显示单位。校准比例默认1，输入已知尺寸与当前测量值的比值即可校准，只影响当前预览。测量标记不会写回附件，不产生新版本，不触发审批。

支持常见二维 LINE/多段线端点、圆心和圆弧端点捕捉；隐藏图层不捕捉，未展开的块及非XY平面不做推测性捕捉，可自由选点。点位显示捕捉类型；自由选点精度由选点决定。当前只在模型空间开放测量，纸空间测量禁用，避免视口比例误差。不含曲线长度、面积及原生尺寸标注编辑。

## DXF

无须安装服务器转换器。浏览器使用自托管 dxf-viewer/WebGL，在独立 Worker 中解析和准备几何。支持文字、圆弧、块、尺寸等实体的范围以锁定版本 dxf-viewer 为准。数据上限32MB、20万顶层实体、100个含实体布局。加密或二进制 DXF 明确报错，不返回伪造或空白成功页面。

## DWG

DWG 在服务器隔离的临时目录中转换为 ASCII DXF，再使用同一个交互式查看器；原始 DWG 不变，也不转 PDF。安装并验证 ODA File Converter 后，在 bestcrm 的 systemd 环境配置绝对路径：

```
CAD_DWG_CONVERTER=/opt/bestcrm-cad/oda-27.9-f2a8e125e84e/convert
```

转换器由管理员从 ODA 官方来源单独安装并确认其使用条件，本仓库不附带转换器或代替供应商授权。程序以应用服务用户、shell:false、固定参数、90秒超时执行：

```
ODAFileConverter INPUT_DIRECTORY OUTPUT_DIRECTORY ACAD2018 DXF 0 1 drawing.dwg
```

当前云端ODA 27.9只附带xcb平台插件，受控包装脚本通过xvfb-run启动独立虚拟显示，禁用X11 TCP监听并强制QT_QPA_PLATFORM=xcb。系统需安装xvfb、xauth、libglx0、libopengl0、libgl1、libegl1；以实际依赖检查和样本验证结果为准。执行程序或包装脚本必须是管理员控制、应用服务用户不可写的绝对路径。每进程最多2个同时转换，临时文件成功、失败后都清理。没有配置时 DWG 页面明确提示转换器未配置，DXF 仍可使用。不会自动安装软件，不会把文件发送到外部网站。

当前接口为已登录用户的 GET /opportunities/:id/attachments/:attachmentId/cad-data?layout=布局名称。输出只供只读渲染，客户端没有保存、上传或审批操作。预览临时 DXF 不作为新的业务版本保存。

## 构建

主应用不增加 npm 运行依赖。预构建浏览器资源已包含在 src/public/assets 中。开发者重新构建：

```
cd tools/cad-viewer-build
npm ci --ignore-scripts
npm run build
```

保留 package-lock.json 和资源中的第三方许可。dxf-viewer 1.0.50 使用 MPL-2.0，原始包及对应源码链接列于 /assets/cad-third-party-notices.txt；其代码未修改，仅打包。字体来自 Google Fonts 的 Noto Sans SC（SIL OFL）；静态400字重由 fontTools 4.60.1 从官方可变字体生成，字体及 OFL.txt 一起分发。

## 验收

- 服务测试：布局隔离、文本保留、坏文件/加密内容/大小限制、哈希校验、移除文件、路径穿越、转换参数、超时和临时文件清理。
- 路由测试：登录、商机权限、跨商机附件、已移除附件、无保存入口、数据不缓存；Worker 仅允许同源与当前浏览器生成的 blob 数据。
- 浏览器：中文、图层、圆弧、块、模型/布局切换、缩放/全图、桌面及手机横屏。
- 上线前仍须安装实际 DWG 转换器，并使用客户未加密 DWG 核对。模拟转换测试不能替代真实 DWG 转换验收。
