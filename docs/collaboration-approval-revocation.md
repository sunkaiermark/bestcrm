# 逐文件撤销批准

技术方案、价格核算的最新有效文件，在当前准备阶段可由本商机指定技术审批人撤销本人作出的批准。每个文件一行，原审批人可见“撤销批准”；点击后展开原因栏，输入并保存原因，再确认撤销。需登录、CSRF校验、原因（最多2000字）和当前需求轮次标识。

文件退回待审核，不自动删除、撤回上传或退回作者修改。原审批人随后可重新同意，或填写驳回意见退回提交者。兄弟文件状态保持不变。清除的是当前批准状态，原批准人、时间、意见、批准版本号完整写入现有工作包事件；此前批准事件保留。界面“批准撤销记录”显示原因、原批准时间、撤销人和撤销时间。通知原上传者。

商机、工作包、文件加锁后重新校验，拒绝已替换/移除文件、旧版本、已关闭需求轮次、沿用文件、非本人批准及已经用于待审批或生效正式报价的文件。商务报价待审批时先处理或撤回报价；对外生效和历史版本通过新修订处理，不改写冻结依据。撤销使工作包重新待审核，正式报价就绪条件重新计算；未重新批准前不能按已批准依据提交正式报价。

沿用现有updated事件记录JSON动作approval_revoked，不新增数据库迁移。现有文件、版本和活动记录不删除。功能上线前仍需独立提交部署；不会直接修改800054线上审批数据。
