# BESTCRM 网页 Office 编辑

使用自有 ONLYOFFICE Docs 文档服务器；不开通配置时原预览功能不变。支持 DOCX、XLSX，其他格式仍只读。

## 启用配置

先运行数据库迁移 131，再在 BESTCRM 的服务环境文件中配置：

```
OFFICE_EDIT_ENABLED=true
OFFICE_DOCUMENT_SERVER_URL=https://docs.example.com
OFFICE_CRM_BASE_URL=https://crm.example.com
OFFICE_JWT_SECRET=<至少32字节的随机密钥，与文档服务器完全相同>
```

占位域名必须替换为实际地址。生产环境两端均要求 HTTPS，互相能访问；浏览器也需要访问文档服务器。不要把密钥写入仓库或聊天。
文档服务独立部署，使用官方支持的版本与许可证；关闭示例应用，启用 JWT。未配置时不会显示在线编辑按钮。

## 保存行为

商机附件预览 → 在线编辑 → 修改 → 编辑器内保存。只有文档服务回调并成功归档后，才生成一个版本。重新打开、没有修改、重复保存同一内容不会增版。原文件不覆盖，新文件独立存储；版本记录可下载历史文件。
内容摘要忽略 ZIP 时间戳、压缩差异及 Office 修改时间/最后编辑者/修订计数，保留正文、公式、格式、图片等实际包内容。不同编辑器对 XML 的改写仍可能构成内容差异，需真实文档联调验证。
保存不触发提交或批准。已审批绑定附件、已提交草案、工作包文件及邮件原附件只读；沿用商机可见权限及对应阶段附件修改权限，保存时再次检查。

## 回调与网络

文档服务读取 `/office-service/:sessionId/file`，回调 `/office-service/:sessionId/callback`。回调不使用浏览器登录/CSRF，而验证共享 JWT、会话键、有效期与编辑人当前权限。只允许从配置的文档服务源下载保存结果，禁止跳转，限制25MB。维护期间暂停保存，文档服务应重试。

## 上线验收

用专用测试商机分别测试 Word 表格、Excel 公式/合并单元格；修改并保存应出现新版本，重复保存不能增版；两个用户并发打开应阻止分叉；提交审批后保存应被拒绝；重启 CRM 后仍可保存已有有效会话。核对原附件与历史版本可下载。
尚未连接真实文档服务前，不应声明在线编辑已通过联调。
