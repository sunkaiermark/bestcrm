# 证据安全

POST /sources/{externalLeadId}/evidence 使用 multipart，仅接受 metadata JSON 字符串及一个 file。先完成 HMAC 和正文哈希校验，再校验元数据、文件名、扩展名、MIME、魔数、实际大小及 SHA256。

单文件最大 25 MiB，整个 multipart 最大 27 MiB。允许 pdf、png、jpg、txt、wav、mp3；文件名不含路径、控制字符或双点。文本必须为无 NUL 的有效 UTF8。元数据可关联本来源已经接收的交互事件，不能跨来源引用。

文件先写入私有 .quarantine。ClamAV 返回 clean 后移至私有随机存储键，并在接收事务内记录证据元数据。未启用扫描器、扫描错误或恶意文件失败关闭，不产生可用证据。事务失败会清理本次已放行文件；进程突然终止可能留下孤儿文件，运维需按数据库 storage_key 对账，不能盲删。

来源接收不依赖文件上传成功，可使用独立事件补传。证据不可覆盖，只能新版本追加。浏览器下载重新检查登录、来源权限、扫描状态、大小及哈希，强制附件下载并设置 nosniff 和 sandbox。没有公开静态文件映射；未授权用户无法下载。

数据库保留元数据，文件字节放私有存储。其他业务只关联同一来源，不复制附件。上传状态和人工关联分开。测试使用合成文件及注入扫描结果，不代表本机已安装或实际验证 ClamAV。
