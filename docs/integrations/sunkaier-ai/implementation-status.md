# AI Source 实现状态

本次实现 CRM AI Source 持久化工作区及默认关闭的机器 API，替代原先仅浏览器内存的演示能力。旧 /ai-source-preview/ 布局样稿已移除，正式工作区为 /ai-sources。

## 已实现

- 新增迁移 121：来源、事件、幂等、nonce、审计、候选、证据、业务关联与不可变事实保护。
- 固定页头、来源分类、数据库分页、全库授权模糊查询、详情、归档、逻辑删除、恢复、分派和审计。
- 人工转入既有待审核 Lead 流程、关联有权处理的已有商机；业务资料不被来源更新覆盖。
- sources 提交、交互追加、证据上传、最小状态与 reconciliation；专用 HMAC、轮换、nonce、范围与速率控制。
- 受控文件隔离、格式大小哈希校验、ClamAV 接口及受权完整性下载。
- 签名 SDK client.mjs、OpenAPI 与合成示例、本地持久化运行器。

## 未启用及明确限制

未部署、未连接生产、未切官网流量、未发送真实数据。真实 SUNKAIER AI 项目源码未改动，本次提供可供其采用的契约与客户端；它自己的 outbox 改造仍由 AI 项目实施。未把 AI 全球搜索程序扩展到 CRM。

未实际验证本机 ClamAV 服务；扫描无 clean 结果即拒绝文件。企业注册号在 CRM 没有对应主数据字段，仅保存等待人工核实。经理来源可见范围沿用现有全局模型，没有新建团队体系。旧浏览器演示不用于业务持久化。

OpenAPI 是合法 JSON 形式的 YAML，可由 build-ai-source-openapi.mjs 从 Zod 字段规则重新生成；条件校验（如同意时间、公开 URL限制）还需参照 contracts.mjs 和映射说明。

测试实际结果及本地 Git 提交见 completion-review.md；不把设计文档或模拟扫描当作真实生产联调通过。
