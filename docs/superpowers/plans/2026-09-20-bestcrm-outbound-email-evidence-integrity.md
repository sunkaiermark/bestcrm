# BESTCRM Outbound Email Evidence Integrity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Ensure every CRM-sent customer email has one immutable MIME byte stream archived and hash-bound before SMTP submission, then reconcile the NetEase Sent-folder observation without duplicating or mutating the logical message.

**Architecture:** Keep email_messages as the canonical logical message. Add one immutable email_outbound_mime_artifacts row and file for the exact bytes generated by CRM; SMTP receives those exact bytes. Provider Sent-folder MIME remains separate mailbox-delivery evidence. This is the first integrity slice; legacy attachment hashing and full disaster-recovery rehearsal are later slices.

**Tech Stack:** Node.js ESM, PostgreSQL, Nodemailer stream transport/raw submission, SHA-256, Node test runner.

---

## Boundaries

- Preserve the current uncommitted purge and shared-mailbox changes.
- Do not change lead screens, opportunity workflow, permissions, or Singapore services.
- Do not commit or deploy before explicit user approval.
- A crash before SMTP must leave the message retryable and reuse the same verified MIME.
- A crash after SMTP remains delivery-ambiguous until Sent-folder reconciliation; never resend silently.
- NetEase Sent raw evidence belongs to email_message_mailbox_deliveries, not the inbound-only email_messages.raw_message_id.

- [x] **Step 2: Create migration 066**

~~~sql
CREATE TABLE IF NOT EXISTS email_outbound_mime_artifacts (
  id bigserial PRIMARY KEY,
  message_id bigint NOT NULL UNIQUE REFERENCES email_messages(id) ON DELETE RESTRICT,
  stored_path text NOT NULL UNIQUE CHECK (
    btrim(stored_path) <> ''
    AND stored_path LIKE 'email-outbound/%'
    AND stored_path NOT LIKE '%..%'
  ),
  file_size bigint NOT NULL CHECK (file_size > 0),
  sha256 char(64) NOT NULL CHECK (sha256 ~ '^[0-9a-f]{64}$'),
  rfc_message_id text NOT NULL CHECK (btrim(rfc_message_id) <> ''),
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX IF NOT EXISTS email_outbound_mime_artifacts_sha256_idx
  ON email_outbound_mime_artifacts(sha256, id);

CREATE OR REPLACE FUNCTION bestcrm_protect_email_outbound_mime_artifact()
RETURNS trigger AS $$
BEGIN
  RAISE EXCEPTION 'Outbound MIME artifacts are immutable';
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER email_outbound_mime_artifacts_no_change
BEFORE UPDATE OR DELETE ON email_outbound_mime_artifacts
FOR EACH ROW EXECUTE FUNCTION bestcrm_protect_email_outbound_mime_artifact();
~~~

- [x] **Step 4: Add the raw MIME builder**

~~~js
async function buildRawMime(mailOptions, dependencies) {
  if (dependencies.buildRawMime) return Buffer.from(await dependencies.buildRawMime(mailOptions));
  const imported = await import('nodemailer');
  const nodemailer = imported.default || imported;
  const streamTransport = nodemailer.createTransport({
    streamTransport: true,
    buffer: true,
    newline: 'unix'
  });
  const result = await streamTransport.sendMail(mailOptions);
  return Buffer.from(result.message);
}
~~~
