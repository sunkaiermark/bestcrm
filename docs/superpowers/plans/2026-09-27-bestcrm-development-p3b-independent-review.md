# BESTCRM 新产品开发 P3b：结论候选的独立审核记录

状态：本地方案已获审核通过；未提交、未部署、未迁移生产数据库。P3a 数据底座也已获审核通过。本切片仍不开放菜单、审核接口、资料上传/下载、资产发布或商机引用。

## 本切片的边界

迁移 `087_development_asset_candidate_review.sql` 新增只追加的 `development_asset_candidate_reviews`：每个候选结论修订最多一份独立审核决定，结果为 `endorsed` 或 `revision_required`，必须记录理由、审核人和服务器时间。`endorsed` 只表示候选结论通过内部独立审核，**不等于资产发布、资料解密或对客使用许可**。P3a 的 `blocked_pending_policy` 不变，也没有 `development_assets` 发布表。

数据库写入时锁定课题，核对候选仍指向该课题的最新结论修订；审核人必须同时为在职技术经理和该课题当前有效成员（已加入且未退出），且不能是结论作者或候选提议人。P2 的代理任命不适用于 P3 审核。审核期间锁定角色与成员记录，避免角色或成员资格在决定提交前被并发撤销。审核记录和审计事件不可覆写或删除；新修订须另立候选，不能沿用旧审核。

## 验证与后续门槛

- 在独立临时 PostgreSQL 上完整迁移两次，确认 `087` 只应用一次；覆盖过期修订、作者/提议人自审、普通成员、非课题成员、已停用或已撤销角色的技术经理、失效及未来才加入的成员、仅有 P2 代理、非法结果、重复决定、不可变审计及合格独立审核。测试不连接生产数据库。

- 受限资料读取范围、文件类型/大小和安全扫描要求未定前，不开放文件操作；资产发布及商机对客引用须在各自规则确认并完成授权与恢复测试后另行实现。用户审核前不得提交或部署。
