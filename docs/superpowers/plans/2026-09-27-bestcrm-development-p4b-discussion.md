# BESTCRM 新产品开发 P4b：课题内部讨论

状态：本地实现，未提交、未部署、未启用。本段接续 P4a 的课题及成员工作区；不表示 P4 或新品开发模块整体完成。

## 范围与边界

- 当前在职、有效课题成员可在课题详情发表内部讨论。意见与探索发现按时间保存；不允许编辑或删除原文。非成员、资格已结束者和停用账号不能读取或发表。
- 讨论只是协作证据，不是概念方案批准、正式设计交接、资产发布或对客引用；不能附加研究原件，也不改变现有研究文件的逐文件授权。
- 每条正文去除首尾空白后须为 1–4000 字符。课题页按事件 ID 倒序分批显示，每批最多 30 条，可向前翻阅；页面转义作者和正文。
- 复用 P1 的不可变 `development_events`，事件类型为 `discussion_comment`，`metadata` 仅保存 `body`。迁移 091 加入正文形状约束及在职有效成员触发器校验；服务层和仓储在写入时也进行权限检查。
- 课题入口仍由 `DEVELOPMENT_WORKSPACE_ENABLED=false` 默认关闭。不改商机、客户、邮件、产品分类或跨系统集成。
