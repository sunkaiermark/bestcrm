# BESTCRM 联系人代码前缀修订

日期：2026-09-09

## 决策

联系人代码由原来的 8 位 `CT` + 6 位数字，统一改为 7 位 `L` + 6 位数字：

```text
CT000301 -> L000301
```

客户代码继续使用 `C` + 6 位数字，例如 `C000201`。

## 数据规则

- 迁移 `052_contact_code_l_prefix.sql` 将所有现有 `CTxxxxxx` 联系人代码转换为对应的 `Lxxxxxx`，数字部分保持不变。
- 新联系人继续使用现有全局序列 `contact_code_seq`，默认生成 `L` + 6 位数字。
- 联系人代码仍然全局唯一、非空且创建后不可修改。
- 应用继续把 `contactCode` 当作数据库读取模型字段，不在关联业务表复制联系人代码。
- 历史已冻结或已生成的外部文件不回写；CRM 当前记录及后续生成内容使用新代码。

## 验收示例

```text
C000201 · 江苏恒新材料有限公司
L000301 · 陈伟
```
